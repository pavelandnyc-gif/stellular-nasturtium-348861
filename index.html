Falta conectar la base de datos

La aplicación está lista, solo necesita las llaves de Supabase (2 minutos):

  1. Crea un proyecto gratis en supabase.com.
  2. Abre SQL Editor y ejecuta el archivo supabase/schema.sql.
  3. Ve a Project Settings → API y copia el Project URL y la anon key.
  4. Pégalos en assets/js/config.js y vuelve a cargar esta página.
